B.6 · Cursor Customizado — Prós, Contras e Acessibilidade
✓ Prós
  • → Reforça a identidade visual gold da marca
  • → Cria sensação premium e diferenciada
  • → Efeito "hovered" direciona atenção para CTAs
  • → Implementação leve (CSS + 10 linhas de JS)
⚠ Contras & Riscos
  • → Mobile/touch: cursor nativo não existe, CSS cursor:none é inerte — sem impacto
  • → Teclado: ocultamos o cursor mas não o foco — :focus-visible deve ser sempre visível
  • → Acessibilidade: usuários com baixa visão podem depender do cursor do SO. Recomendado: toggle opt-in via preferência de usuário
  • → Performance: mousemove deve usar requestAnimationFrame ou será chamado em excesso

RECOMENDAÇÃO: Implementar com prefers-reduced-motion + desativar em dispositivos touch (pointer: coarse). Garantir que todos os elementos interativos tenham :focus-visible estilizado com outline gold de 2px.
